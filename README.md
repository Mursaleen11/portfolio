# Developer Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. It can be hosted free with GitHub Pages.

## 1. Personalize before publishing

Open `index.html` and replace:
- `Your Name` with your real name.
- `YN` with your initials.
- `YOUR-EMAIL@example.com` with your email.
- `YOUR-GITHUB-USERNAME` with your GitHub username.
- `YOUR-LINKEDIN-USERNAME` with your LinkedIn username.
- Project descriptions and links with projects you have actually built.

Also edit the About section and skill list so they accurately represent your experience. Remove any technology you cannot confidently discuss in an interview. Skill-bar percentages are decorative placeholders; adjust or remove them.

## 2. Preview locally

Open `index.html` in your browser. No build tools or dependencies are required. An internet connection is used only for the Google Fonts import; the site still works without it.

## 3. Push to GitHub

Create a new **public** repository, for example `my-portfolio`.

From this folder, run:

```bash
git init
git add .
git commit -m "Add developer portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-GITHUB-USERNAME/my-portfolio.git
git push -u origin main
```

## 4. Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish.

Your site address will be:

`https://YOUR-GITHUB-USERNAME.github.io/my-portfolio/`

Use that full HTTPS address in the job form's **Portfolio/Website** field.

## Important

This is a starter template, not a claim that the example projects are completed work. Replace the sample project content and all placeholders before sharing it with an employer.
